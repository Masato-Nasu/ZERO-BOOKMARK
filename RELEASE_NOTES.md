# ZERO BOOKMARK v0.2.0

First public Chrome extension release.

- Save the current web page as a real 0-byte file
- Rename the visible part of the file freely
- Reopen the original page from the 0-byte file
- Share files across computers when the filename is preserved
- No account or server-side URL database
- Minimal permission: `activeTab` only

**Concept:** A bookmark taken out of the browser and turned into a 0-byte object.
